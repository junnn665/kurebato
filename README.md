# 句レバト

© 中濱Games

お題の場面カードを見て五・七・五で一句。先生の査定で **才能アリ／凡人／才能ナシ** が決まる俳句ゲーム。
みんなで同じお題に挑む **対戦** もできます（部屋番号・招待リンク・QR で参加）。

## 遊び方

### ひとりで査定
1. お題を選ぶ（季節でしぼれる・「お題をかえる」で引き直し）
2. 上五・中七・下五を書く（1行目に「古池や 蛙飛び込む 水の音」と貼ると3行に分かれる）
3. 「査定してもらう」→ 点数・判定・先生のコメント・添削ポイント

| 判定 | 点数 |
| --- | --- |
| 才能アリ | 70点以上 |
| 凡人 | 50〜69点 |
| 才能ナシ | 49点以下 |

### 段位
- 新人 → 才能アリを通算 3 回で **特待生5級**
- 特待生・名人は毎回が **昇格試験**：合格ライン（72点〜88点、段位が上がるほど高い）をこえると 1 つ昇格、45 点未満で 1 つ降格
- 特待生5級〜1級 → 名人初段〜十段 → **永世名人**
- 段位と句帳はスマホの中（localStorage の `kure.rank` / `kure.kucho`）に保存

### みんなで対戦
1. ひとりが「部屋を作る」（ラウンド数 1/3/5・制限時間 2/3/5分・査定方式・お題の季節）
2. ほかの人は「番号で参加」、または招待リンク／QR から参加
3. ホストが「スタート」→ 全員同じお題で一句。時間切れになると書きかけで自動提出
4. **みんなで査定**：作者名をかくして、ほかの人の句にスライダーで点をつける（自分の句には付けられない）
5. 点数 = 先生の査定 40% + みんなの平均 60%（「先生だけ」設定なら先生の点のみ）
6. 最下位から順に結果発表。1位の前にドラムロール。ラウンドの合計点で優勝
7. 最後のラウンドのあと、ホストが「待合室にもどる」で同じ部屋のまま次の対戦

- 対戦中は 😀 ボタンからスタンプ（👍 😂 😱 🔥 👏 うまい！ 季重なり 中八！ 才能アリ）
- 途中で入った人は次の対戦から参加。ホストが抜けると、次に早く入った人がホストに
- ページを再読みこみしても同じ部屋に戻れる

## 先生の査定のしくみ（`js/judge.js`）

50点からスタートして、加点・減点を足します。

| 見るところ | 例 |
| --- | --- |
| 五七五 | ぴったり +6／中八 −6／下五の字余り −4／字足らず −5／上五の字余りはゆるめ |
| 季語 | 1つ +8／なし −8／季重なり −5（季節ちがいは −8） |
| 切れ字 | 「や」（上五・中七の終わり）「かな」「けり」（下五の終わり）1つ +5、2つ以上 −5 |
| 言わずに見せる | 「悲しい」「きれい」などの感情語 −6、「ので」「だから」など説明 −4、「ように」の直喩 −2 |
| 五感・具体 | 色・音・匂い・手ざわり・味・光 各 +3（最大 +9）、数字 +3、名詞が多い +3、固有名詞 +2、体言止め +3 |
| 動詞 | 3つ以上 −5 |
| 手垢 | よくある言い回し・「きらきら」系オノマトペ −3／新鮮なオノマトペ +3 |
| お題との距離 | お題に写っているものを3つ以上なぞる −5／お題から飛ばす +2 |

よみ（音数）は形態素解析 [kuromoji.js](https://github.com/takuyaa/kuromoji.js)（Apache-2.0、`vendor/kuromoji` に同梱）で自動で出します。
辞書（約18MB）は最初の1回だけ読みこみ、以降はブラウザのキャッシュから。読みこめないときは「漢字1字＝約2音」で推定し、画面の「よみを直す」で直せます。

季語は `js/kigo.js`（約800語のミニ歳時記）、お題は `js/odai.js` に入っています。どちらも足せば増えます。

## 通信（Firebase）

都道府県ゲーム・お題当てと同じ Firebase Realtime Database（`odeko-ddb38`）を共用しています。
データは `rooms/haiku-<部屋番号>` に入るので、ほかのゲームの部屋とはぶつかりません。
作ってから 24 時間たった部屋は、次に部屋を作ったときに自動で消えます。

ルールは今のまま（`rooms` の下を読み書きできる）で動きます:

```json
{
  "rules": {
    "rooms": {
      ".read": true,
      ".indexOn": ["created"],
      "$room": { ".write": true }
    }
  }
}
```

別の Firebase プロジェクトを使うときは、`js/net.js` の `FIREBASE_CONFIG` を書きかえてください。

## 公開のしかた（GitHub Pages）

1. このフォルダの中身をぜんぶリポジトリのいちばん上（root）に入れて push
2. リポジトリの **Settings → Pages** を開く
3. Source を **Deploy from a branch**、Branch を **main / (root)** にして Save
4. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で遊べる

ビルド不要の静的ファイルだけで動きます。ローカルで試すなら:

```sh
python3 -m http.server 8000
# → http://localhost:8000
```

## ファイル構成

| パス | 内容 |
| --- | --- |
| `index.html` / `style.css` | 画面とデザイン |
| `js/app.js` | ひとりモード（お題・書く・査定・段位・句帳） |
| `js/net.js` | みんなで対戦（部屋・参加・提出・みんなで査定・結果発表・スタンプ） |
| `js/judge.js` | 音数カウントと先生の自動査定 |
| `js/kigo.js` | ミニ歳時記（季語リスト） |
| `js/odai.js` | お題（場面カード） |
| `lib/qrcode.min.js` | 招待 QR（qrcode-generator, MIT） |
| `vendor/kuromoji/` | よみ用の形態素解析と辞書（kuromoji.js, Apache-2.0） |
| `icons/` / `manifest.webmanifest` | アイコン・ホーム画面に追加用 |
